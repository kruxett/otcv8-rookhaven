# First complete Pro sheet — not suitable

The PixelLab Pro job received four COMPLETE native reference sheets, 84 total frames. It generated all twelve requested frames together, and the armor design is more internally consistent, but the result is not acceptable for Rookhaven: actors are roughly60px tall instead of the native roughly32px square figures, projection is upright front/profile rather than the native oblique diagonal body axis, west walking frames face the wrong way, and some sprites cross row boundaries. It is preserved as a rejected experiment, not an approved asset.

No resizing, reposing or hand painting was used to disguise these problems. The native32 retry is a fresh complete joint generation with four denser full base sheets and an exact32px grid.
