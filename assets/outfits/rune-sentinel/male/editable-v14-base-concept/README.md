# Rune Sentinel — basutkast i sydvy

Konceptet är godkänt; denna grafik inväntar godkännande. Native 64×64-canvas med den ursprungliga 32×32-figurens placering, utan skalning. Inga addons ingår.

Öppna `rune-sentinel-base-south.aseprite` eller `.ora` för manuell redigering. Hjälm, torso/armar/höfter, ben och stövlar/runsten ligger på separata synliga målningslager. Ansikte och händer ligger på ett låst lager. Citizen-referensen och fyrkanalsmasken är dolda. Måla i neutralt vitt/grått; ändra färgområden separat i masklagret.

Mask: gult = hjälm, rött = bröstrustning/armar/höfter, grönt = ben, blått = stövlar och runsten. Masken är metadata och ska inte läggas synligt ovanpå målningen. Inga speldata har importerats för denna outfit.

PixelLab-jobb: ce50fdcb-4a42-4908-bb31-10142204ff2f. Exakt PixelLab-finish: 057bad5a-2c49-4f9c-92f1-e49d16ffc498. Original, mask, referenser och målbeslut ligger i `../source/v14-approved-concept/`. Tidigare försök bevaras och är inte godkända. Nästa steg efter grafisk återkoppling: samma fastställda dräkt i övriga riktningar, därefter gångbilder och separata addons.
