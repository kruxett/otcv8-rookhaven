# Rookwarden outfit proposals

Current deliverable: `male/editable-premium-v2/`, a manually editable male premium proposal. Open `rookwarden-male.aseprite` or `rookwarden-male.ora`, or edit `base.png` and `mask.png` separately. Read its README for the four mask channels, native cell coordinates and export instructions. The files contain all four directions and idle plus both native walking phases. No integration is approved or performed yet.

Current corrected base and mask are in `male/source/v9-shoulder-consistency/`. This PixelLab revision fixes the anatomical left-shoulder mantle in all four directions, with three visible feather lobes through all native walking phases. N/W lose the misplaced right-side feather fan. Native hood/face/hand/boot pixels are unchanged from the preceding proposal. The earlier `male/editable-premium/` files are byte-identical and preserved. The underlying premium costume was generated under V7 and made recolorable under V8. Native base/mask layers and the fixed skin/metals use the existing client shader contract. `validation.json` records fresh decoding of 24 Nobleman reference layers from current DAT/SPR, unchanged original face/hand skin and unchanged native boot coverage. The editable manifest records layer readback, mask/alpha checks, color channel isolation and 96 legacy SPR tile roundtrips. Software previews are not native game screenshots.

Artwork history is preserved. V1 generated pose interpretations and V2 clothing-only inpainting were rejected for facing. V3/V4 are native pose baselines, rejected as insufficient garment redesign. V5 redraws clothes; V6 makes that earlier design recolorable. The user requested more exclusivity for a paid outfit, leading to the current V7/V8 premium proposal with fixed bronze hood edging and structured ornament. The current design still awaits manual review and approval.

Each editable cell is the original 64x64 canvas, reconstructed by translation only from the 48x48 working reference. The sheet is 3 columns (idle, step1, step2) by 4 rows (north, east, south, west). No scaling or individual frame centering. Reference extraction is documented in `source/reference/native-poses.json`.

No outfit ID, DAT/SPR mutation, server grant, shop addition or deployment was performed for these outfit proposals. The female proposal remains separate and pending. Actual native outfit rendering, player recoloring and shop unlock checks belong to the future approved integration.
