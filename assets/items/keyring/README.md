# Original Rookhaven Keyring shop artwork

Original PixelLab Pixen artwork, generated directly at 32x32 with a transparent
background: an intact cool steel ring with warm brass keys. This replaces the
stock Broken Key Ring illustration used in DEV10106.

`source/pixellab-keyring.png` is the untouched generator result; `sprite.png`
and `modules/game_shop/images/keyring.png` are byte-identical copies. `preview.png`
is an 8x nearest-neighbour enlargement for inspection only. Provenance, generation
ID and SHA256 are recorded in `source/generation.json`.

The final native image has binary transparency, visible bounds (6,1)-(26,30)
and no clipped edge pixels. It is a static shop illustration, not a new physical
item. No SID/CID, DAT/SPR/OTB records, price or Keychain spell grants change.
